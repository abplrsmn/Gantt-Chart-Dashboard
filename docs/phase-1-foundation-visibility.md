# Phase 1 — Foundation & Visibility

## Goal
Create a clean and readable base so everyone can see where each project currently stands.

## Duration
Week 1–2

## Main Focus
- establish a reliable source of truth
- standardize project identity and phase visibility
- make progress and key dates visible
- launch basic summary output

## Scope
### 1. Project Data Standardization
Each project should have at least:
- project name
- unit
- category
- current phase
- current progress reference
- start/end target where available

### 2. Phase Visibility
Projects should be readable across the main stages:
- Operational Brief
- Design
- Project Control
- Project Management
- Handover

### 3. Basic Dashboard Visibility
Dashboard should show:
- active project visibility
- phase position
- basic progress indicators
- latest summary blocks where relevant

### 4. Daily Summary Foundation
A basic daily summary should answer:
- how many projects are in progress
- how many are near deadline
- how many are in handover

## Deliverables
- cleaned project visibility model
- readable phase tracking structure
- basic project summary output
- dashboard with initial monitoring visibility

## What This Phase Does Not Fully Solve Yet
- full role-based personalized view
- full ownership mapping per person
- advanced pace benchmarking
- deep delay root-cause analysis

## Success Check
At the end of this phase, a manager should be able to quickly answer:
- what projects are active
- what phase each project is in
- which projects are close to deadline
